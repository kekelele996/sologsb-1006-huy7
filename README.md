# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 维护演讲顺序、发言人、语言方向、术语表和紧急通知。
- 自动接入现场文字并进入后传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化、撤销重做与字号偏好恢复。

### 两端分立与一致性

- **各自持有内容**：后台准备端（议程、发言人、术语表、通知）与现场运行端（术语副本、通知副本、稿件队列、提醒）是两份独立状态，分别持久化在 `cue-desk-backstage-v2` 与 `cue-desk-live-v2`。
- **术语版本化**：术语带修订号与历史译法。后台改“指定译法”立即生成事件；现场端对账后，未确认段落立即采用新译法；已确认/已补充的稿件在离开待传队列瞬间**冻结译法快照**，之后永不改写，只在相关段落标注“译法已更新：旧译 → 新译”，可点“知道了”消标。
- **换班交接包**：交班时导出现场端 JSON 交接包（含每条稿件的校验摘要、术语修订指纹与整包 checksum）。接班导入逐条核对：与本班一致则接班继续；对不上则挂起到**值班主管裁定区**，主管签字后选择按交接包接班或保留本班。
- **断网与对账**：两端可分别离线，期间改动与稿件继续进入各自的待发事件箱；恢复后“立即对账”按序号交换、去重（幂等），现场离线条目重跑重复检测。事件逐条事务应用：报文出错只回滚该条（即出错一侧对该事件的接收），其他事件照常生效，坏报文留在发送方待发箱，修复后可重发。
- “对账与离线”页提供两端在线开关、待发箱/对账日志查看，以及报文破坏演练按钮，可直接验证失败隔离。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## 逻辑验证

```bash
npm run verify
```

在 Node 中对六类场景做端到端断言：术语更新对未确认/已确认稿件的不同效果、确认即冻结、双端离线后恢复对账、坏报文只回滚出错事件且不堵塞队列、交接包核对与主管裁定、通知发布闸门。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，后台准备端与现场运行端各自把内容保存在当前浏览器的两个独立 localStorage 键中（不共享一份记录）。清理站点数据会移除本地记录。
