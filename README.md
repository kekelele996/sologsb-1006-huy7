# 会议同传提示台

面向会议管理员和同传人员的现场提示台。**后台准备端与现场运行端各自持有一份记录**：术语表修改后新译法立即生效，已确认传译的稿件不被改写，只在相关段落标注「译法已更新」；断网时两端各自继续记录，网络恢复后各自对账，失败只回退出错的一边；换班时把现场记录导成交接包，接班接着处理，对不上的记录交值班主管决定。

## 功能

- **一端一份记录**：后台准备端（议程、发言人、术语表、紧急通知）与现场运行端（稿件队列、确认、补译、术语提醒）各自保存在本机，同一浏览器打开两个标签页即可自动对账。
- **术语版本化**：管理员修改指定译法后，新录入立即使用新译法；已确认稿件原文不改写，只在相关段落标注「译法已更新：旧译法 → 新译法」。
- **对账与冲突**：两端通过操作日志同步；同一条记录两端都改过时标记冲突，值班主管可「保留本班 / 采用对端 / 合并双方」。
- **失败只回退一边**：对账以事务应用对端操作，任何一步失败只回退本机，对端不受影响，并显示红色回退提示。
- **换班交接包**：一键导出现场记录为交接包（JSON），接班端导入后自动识别同班次/新班次；本班有在途记录而接班包对不上时，交值班主管决定采用、合并或保留。
- **断网继续**：断网时手工录入暂存本机、准备变更记入操作日志；恢复后自动对账，重新执行相似内容检测。
- 自动接入现场文字并进入后传译队列，可手动模拟下一段；基于字符二元组相似度检测重复内容，延迟超过 8 秒显示警告。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号；支持撤销重做。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`（分端保存）+ `BroadcastChannel`（跨标签页对账）

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

- 纯前端离线演示，无后端；两端记录分别保存在浏览器 `localStorage` 的 `conference-cue-desk-v2-onsite` 与 `conference-cue-desk-v2-backstage`。
- 对账通过 `BroadcastChannel` 在同一浏览器的标签页之间进行；跨设备时可用交接包文件传递。
- 清理站点数据会移除本地记录。
